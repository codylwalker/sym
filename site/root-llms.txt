# s2ar.dev — tools for agents, each measured

Paid tools for agents, each answer with a receipt: GitHub code reads (sym),
text grading (score) and image certification (certify), plus a free local
plugin (lens). Every paid route takes GET with query parameters or POST with
a JSON body, costs cents, and answers 402 until paid (USDC on Base over x402,
or a key from a card pack). One ledger pays for all of them; failed calls are
never charged; nothing is kept about a caller.

## sym — read the function, not the file
Local, free (PolyForm Shield): `cargo install starlab-sym`; Claude Code plugin
`claude plugin marketplace add https://github.com/codylwalker/sym && claude plugin install sym@starlab`
(a mod on 2.1.287+: a whole-file Read of a big source file comes back as its
symbol skeleton, the repo map arrives with the first message, map/ls/read/find
and where are tools, every turn's line reads in dollars). Hosted over any public
repository, no install: GET https://api.s2ar.dev/v1/sym/map?repo=owner/repo
(a repo map, $0.01), /v1/sym/ls?repo=&file= (a file's skeleton), /v1/sym/read
?repo=&file=&symbol= (one function's source), /v1/sym/find?repo=&name= (search
by name), $0.005 each; /v1/sym/where?repo=&query= (search by meaning, a semantic
index built once per checkout on our GPU) $0.01; POST with the same fields as
JSON works too. MCP over HTTP: claude mcp add s2ar --transport http
https://api.s2ar.dev/mcp --header "Authorization: Bearer <key>" (tools
sym_map_repo, sym_ls_repo, sym_read_repo, sym_find_repo, sym_where_repo,
score_text, certify_image, buy_credits; every paid tool takes an optional
x402_payment argument). Measured: 12 tasks on ripgrep 14.1.1, 3 runs,
Claude Code 2.1.294 — the mod −21.8% median paired session cost vs plain
(cheaper on 11 of 12; a second run −26.9% on 8 of 12), answers agreed with
plain on 10 of 12 (Haiku judge). The harness and every run: the repo's bench/.
Page: https://s2ar.dev/sym/  Docs for agents: https://s2ar.dev/sym/llms.txt

## lens — the screenshot, not the pixels
Claude Code plugin `claude plugin install lens@starlab`: a whole-image Read over
1024 px on its longest edge comes back downscaled (JPEG q85, the size a model
reads anyway) in the engine's own image shape, with the tokens kept out on the
line; the file on disk is unchanged. Free.

## certify — compress the image, prove the model still reads it
GET https://api.s2ar.dev/v1/certify?image_url=https://…/invoice.png&probe=ocr
(or POST {image_url | image_b64, probe}, or multipart original [+ compressed]
to audit a transform someone else made): the image is compressed to the
smallest version a vision model reads the same way, and the answer is a
signed Assay record; GET /v1/verify/{record_sha256} is free, forever (the
trust layer is never paywalled). $0.01 a call; MCP tool certify_image.
Measured over 12,123 sealed VLM calls: 0.96–0.97 answer retention at 12–22%
billed savings. Page: https://s2ar.dev/

## score — evidence about a text, not an opinion
GET https://api.s2ar.dev/v1/score?text=…&form=haiku (or POST {text, form | spec}):
programmatic verifiers (meter, rhyme, syllables; CMUdict-pinned, replayable)
against a named form (GET /v1/score/forms, free) or an inline spec; scores, a
composite, an accepted flag, diagnostics. $0.005 a call; MCP tool score_text.

## Paying as an agent
Every metered endpoint answers HTTP 402 with a quote listing the rails that can settle right now, plus
how_to_pay, docs and example_get: x402 (USDC on Base; v1 accepts in the JSON body + X-PAYMENT, v2
PAYMENT-REQUIRED header + PAYMENT-SIGNATURE; no key, no account), a card pack under credits_card
($5/$25/$100 in a browser; the key is shown once after checkout, then Authorization: Bearer <key>), and the
Machine Payments Protocol at POST /v1/credits/buy for an agent with a Link wallet. Over MCP, every paid tool
takes an optional x402_payment argument. Money moves only after the answer exists; a failed call is never
charged. Three keyless calls a day are free on each plain route (one for certify); signing in grants $0.50.
The /x402/... mirror of each route (for example GET https://api.s2ar.dev/x402/v1/score?text=&form=) always
answers 402 until paid: the surface for x402 clients and directories. OpenAPI with prices, parameters and
examples: https://api.s2ar.dev/openapi.json · the x402 manifest: https://api.s2ar.dev/.well-known/x402

## Assay — the evidence
Every answer carries a receipt (X-Assay-Receipt: sha256 of the answer). certify answers are Assay records:
sealed, signed by the issuer's key at https://api.s2ar.dev/.well-known/assay.json, and verifiable by anyone,
free, at GET /v1/verify/{record_sha256} (or POST /v1/verify with a record you were handed). The issuer signs
its own day at https://api.s2ar.dev/.well-known/proceedings.json (calls paid, delivered and credited, latency,
what the money cannot buy) and runs under https://api.s2ar.dev/charter.
